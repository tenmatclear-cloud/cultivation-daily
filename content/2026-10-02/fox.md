## 今日發現

2026 年多智能體與工具呼叫已成常態，研究與產品觀察卻同步轉向一個更硬嘅問題：唔單係「答得對嗎」，而係「呢一句到底靠邊段證據撐住」。公開文獻描寫過一種 provenance gap（出處缺口）——工具代理通常會露出完整工具軌跡同最終答案，但很少標明**每一句生成主張**對應邊一次工具觀察、邊個證據單元、屬邊種語義關係。有框架嘗試喺生成當下就為每句綁定結構化出處紀錄，並用 schema、回合對齊、來源真偽同關係合理性做校驗；亦有基準顯示，單純加工具未必提升可靠度，甚至引入噪音。另一條公開測量更刺耳：檢索增強模型可以引用真實、可打開嘅來源，卻喺意圖對齊、來源適配、答案—來源保真度其中一維失敗；讀者仍容易把「有連結」讀成「可信」。再落到個人知識庫，摘要若被當新證據再寫入、外部事實無核對日期地被覆蓋，錯頁會變成之後回答嘅先驗，錯錯相引。對私人 agent 用戶，缺嘅往往唔係更華麗嘅引用 UI，而係一套**極輕、只罩「我會照做」嗰句**嘅出處合約：把「聽起來有據」同「可定位、可複核」拆開，令失敗變成可審計對象，而唔係隱形自信。

## Idea 本身

「主張出處標」（Claim Provenance Tag）係為知識工作者同個人 agent 設計嘅最小證據標籤。規則好窄：任何你準備照做、對外複述、或寫入長期／共享記憶嘅結論，都要喺同一行旁標三欄——**關係類型**、**來源指針**、**核對時間（checked_at，HKT）**。關係類型只允許三種枚舉，刻意對齊「工具觀察→句子」嘅粗分：直接引用＝原文或 raw 回傳片段；忠實壓縮＝不改語義嘅濃縮；推斷＝由證據推出、但證據本身無直接寫出嘅結論。來源指針必須可點開或可搜到：本機路徑＋錨點、訊息／工單 ID、connector 回傳識別、URL＋段落，或明確標「當日口述／現場觀測」。核對時間記錄你（或閘）最後一次對過來源嘅日子，唔係文章發表日，亦唔係模型訓練截止日。

呢套標籤同既有工件分工清楚：穩定 memory 存長期事實；決策收據記「點解我哋揀呢條路」；交接卡交接進行中狀態；沉默合約管「幾時准打擾」。出處標只回答一句——**呢個輸入主張係咪有根、根屬邊種、幾時核過**。預設只罩可行動主張：會觸發發送、付款、合併、對外承諾、改生產設定、或寫入共享知識庫嘅句子。閒聊、純 brainstorm、尚未採納嘅草稿免標，避免全文注釋癖。一句口號就夠：「無標＝唔可當對外事實、唔可一鍵執行、唔可寫入 durable。」若一句裡同時有事實同建議，只為事實段掛標，建議段用「基於上列事實」指回，減少重複標註。

## 點樣落地

1. **劃定罩蓋面並寫成規則**：喺個人 agent 系統提示或筆記規範加兩行——僅當輸出含「建議做 X／結論係 Y／數字為 Z」且你打算採納時，先要求出處標；純探索對話唔強制。把「無標＝降級為待核對草稿」寫死，減少臨場討價還價。第一次落地可用一頁 `provenance.md` 放例子同反例，之後只改呢一頁。
2. **固定三欄微格式**：例如 `[出處｜壓縮｜src:notes/pricing.md#q3｜2026-10-02]`，或筆記表格三欄。禁止「大概有據」「好像睇過」；缺任一欄視為未完成。關係枚舉唔好擴成七種情緒或信心分數，否則審計成本會反噬；信心用「要唔要採納」表達，唔好塞進標籤。
3. **人機同一閘**：對 agent 回覆加後處理——偵測可行動句若缺標，攔截一鍵動作（發送、改檔、落單、合併），只准複製為草稿。人手貼上同一 checklist：寫入共享 wiki／durable memory 前過閘。人機格式一致，先換得過交接同事後複盤，亦方便一週實驗計數。
4. **推斷升級與假執行防呆**：關係＝推斷時，強制加半行「若證據推翻，則……」或指向替代假設。對「宣稱已呼叫工具但你無見過 raw 回傳」嘅結果，禁止標成直接引用，最多標推斷或待核——公開審計亦提醒，捏造工具執行可以對終端分數隱形；個人場景嘅對應動作係：未見到 raw，就唔畀直接引用權。
5. **每週掃過期與 supersession**：對 `checked_at` 超過 14 日、且涉及外部價格、政策、API、職稱、配額嘅主張，列「待複核」。複核後更新時間與指針；若事實變咗，用「被 YYYY-MM-DD 條目取代」註記，禁止沉默改寫正文，打斷摘要互相引用成環。過期清單可以係一個簡單表格，唔使上監控平台。

## 風險同取捨

過度標註係第一殺手：若修辭句、過渡句都要出處，人會關規則。因此罩蓋面必須窄，並接受大量未標草稿係健康狀態，而唔係合規失敗。第二，標籤可被偽造——虛構回合號或貼一個無關但真實嘅 URL；緩解係優先信任你控嘅系統（本機檔、已驗證 connector 原始回傳、你親手打開過嘅頁），並把「無 raw」一律降級。第三，三欄解決唔到來源適配：真文可以錯域；標籤只逼顯關係類型，令錯配可被審計，判斷仍靠你對領域嘅常識。第四，唔好同決策收據、交接卡混欄——混用會令「為何決定」同「輸入有根」都變糊，複盤時揀唔到該改邊一層。第五，有標唔等於對：公開測量裡「真引用仍誤導」說明，出處標把失敗變成可定位對象，而唔係自信語氣嘅替代品。成本係每條採納句多幾秒到半分鐘；回報係少一次把推斷當事實發出嘅對外事故，以及知識庫少一層互相背書嘅幻覺環。

## 一週內可驗證小實驗

選一條你本週真會用 agent 或筆記輔助、而且有對外或寫庫後果嘅工作流（例如回覆合作方報價、整理競品數字、更新共享知識庫一頁）。規則：由即日起連續七個日曆日，凡你採納並執行（發出訊息、改共享檔、寫入 durable memory、或觸發付費／合併）嘅可行動主張，必須帶齊三欄出處標；缺標則改寫成「假設／待查」或延後執行。每日結束只記兩個整數：當日採納句總數、其中完整出處標句數；另用一行筆記記下「改標事件」（原本當直接引用、標完先改成壓縮／推斷／待核）。唔計未採納嘅草稿，避免分子分母灌水。成功標準：**連續五個工作日，採納並執行嘅可行動主張出處標完整率 ≥ 90%，且至少出現兩次改標事件**——有改標先證明閘攔截到真實風險，而唔係只係多打咗幾個括號。若五日內零改標但完整率達標，延長三日並刻意抽查兩條「看起來好肯定」嘅句子對 raw 來源，確認唔係格式合規、實質空轉。
